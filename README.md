🍷 Vinheria Agnello 

📌 Descrição do Projeto A Vinheria Agnello é uma empresa familiar localizada em São Paulo, com mais de 15 anos de atuação no mercado de vinhos. Seu principal diferencial é o atendimento personalizado, no qual os vendedores auxiliam os clientes com recomendações sobre uvas, regiões, vinícolas e harmonizações. Devido ao impacto da pandemia, a empresa enfrentou uma queda no movimento da loja física, levando muitos clientes a migrarem para o ambiente online. Diante desse cenário, o proprietário Giulio, com o apoio de sua filha Bianca, decidiu investir na criação de um portal de e-commerce. Este projeto tem como objetivo desenvolver um site institucional inicial para a vinheria, com foco na experiência do usuário, organização das informações e apresentação clara dos produtos. 

🗂️ Estrutura do Projeto O site é composto pelas seguintes páginas: index.html (Início) Página principal com apresentação da vinheria e destaque para os principais conteúdos. historia.html (Nossa História) Apresenta a trajetória da empresa, desde sua origem até os dias atuais. produtos.html (Produtos) Exibe vinhos disponíveis, com imagens, listas e tabelas informativas. harmonizacao.html (Harmonização) Sugestões de combinação entre vinhos e alimentos, facilitando a escolha do cliente. contato.html (Contato) Informações de contato e formulário para envio de mensagens. css/style.css Responsável pela estilização geral do site. css/efeitos.css Arquivo adicional criado para concentrar animações, transições e efeitos visuais. 

🎨 Efeitos Visuais Para tornar o site mais moderno e interativo, foram adicionados efeitos visuais utilizando CSS, separados em um arquivo específico (efeitos.css) para melhor organização do projeto. 

✨ Pseudo-classes Foram utilizadas pseudo-classes para melhorar a interatividade da interface: :hover → aplicado em links, botões e imagens, gerando respostas visuais ao passar o mouse :focus → utilizado em campos de formulário e navegação, destacando elementos ativos :nth-child() → usado para alternar cores em linhas de tabelas :not() → aplicado no menu para diferenciar elementos específicos :active → utilizado em botões, simulando o efeito de clique Essas interações ajudam a tornar a navegação mais intuitiva e agradável. 

🎭 Pseudo-elementos Foram utilizados pseudo-elementos para enriquecer o visual sem alterar o HTML: ::first-letter → destaque na primeira letra dos parágrafos ::after → adição de elementos decorativos em títulos ::selection → personalização da cor ao selecionar textos Esses recursos contribuem para um design mais refinado e detalhado. 

💫 Animações Foram criadas animações com @keyframes para dar mais dinamismo ao site: Animação de entrada: o conteúdo aparece suavemente ao carregar a página Efeito de pulsação: aplicado no botão do banner para chamar atenção do usuário As animações foram aplicadas de forma leve para não prejudicar a usabilidade. 

🔄 Transições Transições suaves foram aplicadas em elementos interativos como links, botões e imagens. Isso permite que mudanças de cor, tamanho e posição ocorram de forma gradual, proporcionando uma experiência visual mais fluida. 

🎢 Transformações Foram utilizadas transformações CSS para tornar a interface mais dinâmica: scale() → aumento leve de elementos ao interagir rotate() → leve rotação em imagens translate() → deslocamento sutil de botões e links Esses efeitos ajudam a transmitir modernidade e resposta visual às ações do usuário.
